# Training pass icons

Store icons for the 7 training-area game passes, made 2026-10-09 in the style of Build the Pyramid's gym pass icons, with our own design, not a copy.

- **Look:** a glossy disc in that training pad's color from the game (2x yellow, 5x cyan, 10x purple, 25x orange, 50x red, 75x pink, 100x emerald), a 3D dumbbell, and the multiplier ("2x") in bold white with a dark outline.
- **Files:** `assets/icons/training_2x.png` ... `training_100x.png`, 512×512 with transparent corners.
- **Made in Blender:** a separate "PassIcons" scene in `trees.blend` (the tree scene is untouched). That file hasn't been saved since, so save it to keep the scene for re-renders.
- **Uploaded** to all 7 passes on 2026-10-09 and waiting for Roblox's image review. The first upload briefly put two icons on the wrong passes; all 7 were re-uploaded correctly. Check the store page once the review is done.
- Possible next step: show these icons on the in-game SHOP's training cards too.
