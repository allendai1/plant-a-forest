# M0. Project setup

Status: **approved 2026-10-06.** Decisions: ProfileStore copied in M8 (no Wally); add `luau-lsp`; no git, work directly in Studio; sync into the open Studio place.

## 1. Goal

From `docs/MVP_PLAN.md`: a Rojo project with `src/shared`, `src/server`, `src/client` and strict Luau everywhere; Selene and StyLua set up; `GameConfig.luau` and `HexGrid.luau` synced into ReplicatedStorage; a Remotes module defining every RemoteEvent/RemoteFunction in one place.

Done when: the project syncs into an empty place and runs with no errors.

## 2. Design check

- **Layout and startup** follow `docs/ARCHITECTURE.md` section 2: one `init.server.luau`, one `init.client.luau`, everything else ModuleScripts, two-phase `init()` then `start()`.
- **Remotes** follow section 5: names live in `Shared/Remotes.luau`, the server creates them in `ReplicatedStorage.Remotes` at startup, and the client only waits for them. `DevCommand` is left out of the list on purpose; DevService creates it only in Studio.
- **StreamingEnabled** is on from the start (ARCHITECTURE section 1, "about 3,000 trees"). It's set in the Rojo project file, so it can't be forgotten in Studio.
- No gameplay in M0. `GameConfig.luau` and `HexGrid.luau` are not changed.
